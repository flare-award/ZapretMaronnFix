# Zapret Control (ZapretMaronnFix)

Полнофункциональная десктопная программа управления для Zapret с изолированным ядром, проверкой обновлений, прямым запуском стратегий и подбором профилей по задержке и целевым сервисам.

## Структура проекта

- `ZapretControl.bat` - точка запуска десктопного приложения на Windows 10/11 (при первом запуске автоматически собирает нативный `ZapretControl.exe` с системным треем и правами Администратора через встроенный в Windows компилятор .NET Framework).
- `zapret/` - изолированная папка всех оригинальных файлов Zapret (`general*.bat`, `bin/`, `lists/`, `utils/`, `service.bat`).
- `app/` - исходный код, локальный сервер управления, нативный Windows-хост и собранный интерфейс (`app/static/`).
- `app/data/` - отдельные настройки программы и резервные копии пользовательских списков (`user-lists-backup/`), которые сохраняются независимо от обновлений папки `zapret/`.

## Ключевые возможности

1. **Прямой запуск стратегий (без `service_install`)**
   Включение выбранной стратегии запускает процесс `winws.exe` напрямую (аналогично открытию `.bat`-файла), не регистрируя скрытую автозапускаемую службу в Windows.
2. **Тестирование и ранжирование по целям**
   Замер доступности и задержки (мс), сортировка по качеству соединения, пингу и имени, а также быстрый подбор лучших стратегий отдельно для `Discord`, `YouTube`, `Google`, `Cloudflare` и `GitHub`.
3. **Управление фильтрами и списками**
   Переключение `Game Filter` (выбор режима `Выкл` / `TCP+UDP` / `TCP` / `UDP` и настройка диапазонов портов), управление `IPSet Filter` (`None` / `Loaded` / `Any` и загрузка актуальной базы с GitHub), подмена активных UDP-фейков (`ACTIVE_DISCORD_UDP.bin`, `ACTIVE_GAME_UDP.bin`) и визуальный/текстовый редактор всех списков доменов и исключений.
4. **Простое обновление Zapret**
   Встроенная проверка выхода новых релизов `Flowseal/zapret-discord-youtube` с отображением текущей и актуальной версий, даты публикации и прямых ссылок. Для обновления достаточно заменить содержимое папки `zapret/` новыми файлами и при необходимости нажать кнопку восстановления своих списков.
5. **Автозапуск и сохранение состояния**
   Поддерживается запуск программы при старте Windows, работа из системного трея и настройка **"Включать стратегию при запуске программы"**, автоматически активирующая последнюю выбранную стратегию со всеми сохранёнными фильтрами.

## Запуск

### На Windows 10 / 11
Запустите `ZapretControl.bat`. Рекомендуется предварительно установить [Node.js LTS](https://nodejs.org/) для полного набора функций живой аналитики и обновлений (также встроен автономный резервный хост на базе .NET / PowerShell).

### Разработка и сборка интерфейса
```bash
cd app
npm install
npm run build
npm start
```
